# DESIGN_DNA: Contempo Austin concept

**One line:** a luxury builder's portfolio presented as a design magazine cover.

| Choice | Decision | Why |
|---|---|---|
| Hero archetype | Magazine cover: giant "Contempo" masthead over a full bleed dusk photo, cover lines (h1 and lede) bottom left, an "in this issue" index bottom right | Luxury builders compete on photography; the current Wix site shows almost none of its text. |
| Display / body | Bodoni Moda 500/700 + Manrope 400/600/700 | High contrast editorial serif, clean modern sans. |
| Palette | `--charcoal` #1c1e20, `--limestone` #ece7df, `--stone` #d9d1c4, `--oak` #4a5a3a, `--pool` #2c6a88, `--copper` #b5653a, `--muted` #625e57 | Pulled from the homes' facades and dusk photography. |
| Signature | The circle: Bohn House's round doorway. Both O's in the wordmark, kicker marks, the circular Bohn photo, name separators, favicon, footer mast | |
| Grid break | Home: the Bird's Eye View bedroom photo drops below the row. Approach: alternating indented steps. Homes: offset middle photo. | |
| Footer | Huge ghosted masthead, phone at display size | |
